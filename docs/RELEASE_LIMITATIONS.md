# Release limitations

## 1. What this release is not

- **Not a publication of findings.** The author's analysis of real data is unpublished. This repository contains methods and
  code, and nothing in it should be read as a statement about rice exports.
- **Not a data release.** No provider data, caches, API responses, derived tables or screenshots are included.
- **Not a production application.** It is a research pre-release: local use only, no authentication, no scheduled refresh, no
  monitoring, not deployed or hosted anywhere.
- **Not endorsed** by any data provider, government body or international organisation.

## 2. Why automated MEF / Data EF retrieval is disabled

The portal's Terms of Use allow use of its content with attribution, but name no licence, state no redistribution conditions,
and prohibit "data mining" or abnormal activity on the site. The publisher has not been asked, and has not confirmed, whether a
script that fetches its files, or a public repository containing such a script, is acceptable. Until written confirmation exists,
this release does **not** include any code that contacts the portal, any dataset identifier or endpoint, or any sample file.

What is provided instead: `scripts/import_mef.py` and `rice_market.ingestion.manual_import`. You download the files in a browser
under the portal's terms and import them from disk; the strict parser validates each file before anything is copied
(all-or-nothing), and the import is recorded in the manifest as a manual import. The parser, schema and checks are identical to
those used for any other source.

## 3. UN Comtrade connector

- Optional, explicit opt-in (`--accept-comtrade-terms`), not part of the default pipeline.
- Depends on a third-party service whose free preview endpoint limits requests (one period per call, rate limits and a usage
  quota). The connector is sequential, paused, cached and budget-limited and stops cleanly on a quota refusal, but it cannot know
  the quota in advance.
- It does not offer bulk, record-level or streaming export. Outputs you create from Comtrade data are subject to the provider's
  licence and policy on use and re-dissemination; the FAQ does not mention publishing code, and its classification of "transformed"
  data is a judgement the provider makes case by case. Ask the provider about your intended publication.
- API behaviour, endpoints and terms can change without notice; the connector has not been re-tested against changes after
  2026-11-01.

## 4. Dashboard

- Three states only: empty (no warehouse), synthetic demonstration, or your own warehouse. Synthetic data are generated by
  `scripts/make_demo.py`, are invented, and carry a banner on every page; they show nothing about real markets.
- Local only (`127.0.0.1`). Do not host it publicly with provider data before checking each provider's terms: some of the tables and
  charts display original figures, and Streamlit tables expose a built-in export toolbar.
- The pages explain definitions (for example that HS 1006 includes paddy; that exporter and importer reports differ) but cannot
  tell you whether *your* data are complete or consistent. Use the completeness and reconciliation tables.

## 5. Methods

- Forecast evaluation is a chronological backtest of simple, fixed-specification methods. A model that beats a baseline in a short
  backtest is not shown to be useful; the bootstrap interval is optimistic (it ignores serial dependence).
- No machine-learning models, prediction intervals or forward forecasts are implemented.
- Benchmark price correlations are exploratory and carry no causal meaning. Benchmark quotations are for other countries' rice and
  are not the exporter's prices.
- HS-revision equivalence and later data revisions by providers are not tracked beyond recording the revision code and
  checksums.

## 6. Testing status

Run and passing at the time of the release audit: ruff, unit and integration tests on synthetic data, repository-hygiene tests,
and a fresh-clone run in a clean environment (see the release report). **Not tested:** GitHub Actions (no workflow has been run for
this repository), Python 3.11, operating systems other than Windows 11, narrow/mobile layouts, long-running or concurrent use.

## 7. Before you publish anything you build with it

Read each provider's current terms; attribute each source; state which figures are your own calculations; do not imply
endorsement; do not redistribute raw provider files without permission.
